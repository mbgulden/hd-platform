🚀 API Overview

The Human Design Engine API is a RESTful service exposing calculation outputs from the open-source OpenHumanDesignMCP engine. Built on Swiss Ephemeris coordinates, calculations are mathematically audited to match global standard practitioners (Neutrino Design, Genetic Matrix).

Developers can calculate natal charts, composite transit conditioning charts, and synastry reports on demand. Output payloads are structured in standard JSON, enabling quick rendering of customized charts or report PDFs.
